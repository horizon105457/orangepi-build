# 变更闸门契约

## 1. Gate A：流程层

允许：

1. 文档
2. 工作区设置
3. 任务入口
4. 审计材料

禁止：

1. 运行行为变化

## 2. Gate B：工程层

允许：

1. 职责收敛
2. 注释与命名整理
3. 目录结构整理
4. 非行为性工程重排

禁止：

1. 镜像内容变化
2. runtime 行为变化
3. boot profile 行为变化

## 3. Gate C：行为层

允许：

1. 局部代码优化
2. 最小行为试点

进入条件：

1. 已完成 Gate A 和 Gate B 文档化。
2. 已指明热区。
3. 已定义最小验证与回滚锚点。

## 4. 当前状态

当前项目已完成 Gate A，并基本完成 Gate B 的文档化前置。

当前仍未进入 Gate C。
